v4.1.0 - Yamaha conversion corrected, and recording from the keyboard works Two of the changes below are ON by default and alter how a style is converted: NOTE LIMITS and GUITAR MODE. A rhythm you converted yesterday can sound different today. Both can be switched off in the IMPORT - YAMAHA group if you prefer the old result, and the program remembers that choice. STYLE MASTER PRO - YAMAHA CONVERSION FIX: Drums no longer end up on a chord track. When a style used both Rhythm Sub and Rhythm Main and PERC - Drum Set 3 was off, the main drum part could be moved onto a chord channel, where a drum note plays as a pitch instead of an instrument. Measured across six styles from six Yamaha series: 70sTV Theme recovered 1904 drum notes, 2-4Oyun 1732, 70sTeensMusical 913. FIX: SFF1 styles now read their own routing table. Styles that store a Ctab record - the s460 and S-series among them - were converted without it, so most of their parts were dropped as undeclared. 8BeatPop kept 908 notes and converted with no bass at all; it now keeps 2512, bass included. FIX: STRIP GUITAR NOISE now works on Yamaha styles as well. Until now it only ran on the Korg side, although v4.0.0 described it without that limit. If you ticked it on a Yamaha style and heard no difference, that was why. FIX: The drum kit a Yamaha style asks for is now actually applied. This was announced in v4.0.0, but the step that reads the kits failed silently on every Yamaha import, so it never took effect. NEW: NOTE LIMITS, on by default. Every Yamaha part states the register its instrument is meant to play in, and the format's rule is that a note outside that range moves by whole octaves until it is back inside. We were ignoring it. Across 63 styles, 97% of bass parts carry a range and the commonest lower limit is E1. Notes only ever move by octaves; none is added or removed, and drum tracks are never touched. NEW: GUITAR MODE, on by default. Yamaha writes some guitar parts as tablature rather than notes: each note names a string and its octave names the position on the neck. Read as ordinary pitches, those parts came out as something that was not a chord at all. They are now rendered as the chord a guitar would actually sound. This reaches 190 parts across 18 of 40 styles in our test collection. IMPROVED: The import log now reports when it raises volumes, and which parts it moved into C from their written key. Both were being computed and then lost. STYLE MASTER PRO - KETRON STYLES FIX: Voices now match what the keyboard plays. A .kst stores each instrument twice - as a MIDI program change and inside the KSHP table - and the Event reads the KSHP one. We were reading the other. Across 13 factory MIDI styles the two disagree 30 times, and every single file has at least one, most often on Bass and Chord 1. Tracks were therefore labelled, and sent to the keyboard, as voices the Event never plays. FIX: Voice names now match the Event's own display. A program change carries the number one below what the keyboard shows, and part of the import was reading it as-is. FIX: An empty part reads as empty. A track with no voice assigned showed a bank and program number the Event never plays. It now shows a dash, the way the keyboard does. IMPROVED: Your own drum kits are named. Kits captured with DRUM CALIBRATE are now used when naming a track, so a kit you built and named yourself appears by that name instead of User DK 4. IMPROVED: Groove parts are recognised. Drum Set 3 can hold either a drum kit or one of the Event's own GROOVE patterns. The second case now reads Groove 42 instead of an invented kit name. STYLE MASTER PRO - CALIBRATION AND RECORDING NEW: The name field suggests as you type. Type three letters and the matching voices appear with their family beside them - grand finds Bright Grand and Classic Grand, muted shows both the BRASS and the GUITAR one. Any name you type by hand still goes through unchanged, which matters for kits you built yourself: the list is an offer, never a gate. NEW: Calibration progress is shown. The banner now says how many voices and kits you have captured and where you left off. Calibration is long and nobody finishes it in one sitting. FIX: Recording from the keyboard works. Several faults together made it appear to do nothing: the whole first bar of every take was discarded, a key already held when the count-in ended was lost, two drum sounds were being filtered out as metronome echo, and recording onto a muted track produced notes nobody could see. FIX: Drum Set 3 records on the right channel. The editor and the recorder held different channel tables, so a block could not be added to a track that was audibly playing. IMPROVED: You do not have to calibrate everything - only the voices your own styles use. The dialog now says so. IMPROVED: LIVE DK MAPPER no longer says Korg throughout, which suggested it only worked with a Korg. It works with any make - Korg, Yamaha including Genos, or another Ketron. MAIN WINDOW FIX: Opening Lyrics Converter no longer closes the main window. A sidebar module runs as a second copy of the program, and the cleanup that removes leftover processes mistook the main window for one. Style Master Pro was protected from this in v3.0.4; Lyrics Converter arrived later and was not. IMPROVED: The module buttons are easier to read. Each name is centred on its own line beside the icon, in capitals, and the two longest ones now break onto a second line instead of losing a letter at each end. IMPROVED: The module you are working in glows softly, so a glance tells you where you are without reading all six. NEW: Hovering over a module explains what it does. The same for the UI Scale button and About. FIX: Tooltips now carry the program's own colours, and no longer run off the edge of the screen. They followed the Windows theme, so on a light desktop they opened as pale boxes over the dark window. FIX: Making the window shorter no longer lets one module's colour run into the square below it. 3
Smart intruder detection
🛡 Smart protection

Event Studio Pro uses smart technology that automatically detects any files which do not belong in the USER_VOICE, USER_STYLE, REGISTRATION or PERFORMANCE folders — for example text files, images or any other file types the Ketron Event device does not recognise. These are called "intruders".

When you load one of these folders into the program, any intruders are shown to you and the program offers three options for each of them:

  • Delete — permanently remove the unauthorised file
  • Move — relocate the file somewhere else on your PC (outside the folder)
  • Ignore — leave it as is (dismiss the warning for this session)

This mechanism prevents unauthorised files from causing potential problems with the Ketron device during playback or loading — for example freezes, errors or unexpected behaviour caused by foreign files that should not be there.

Rilevamento intelligente degli "intrusi"
🛡 Protezione intelligente

Event Studio Pro utilizza una tecnologia intelligente che rileva automaticamente tutti i file che non appartengono alle cartelle USER_VOICE, USER_STYLE, REGISTRATION o PERFORMANCE — ad esempio file di testo, immagini o qualsiasi altro tipo di file che il dispositivo Ketron Event non riconosce. Questi file vengono chiamati "intrusi".

Quando si carica una di queste cartelle nel programma, tutti gli intrusi vengono visualizzati e il programma offre tre opzioni per ciascuno di essi:

  • Delete — rimuovere definitivamente il file non autorizzato
  • Move — spostare il file in un'altra posizione sul PC (al di fuori della cartella)
  • Ignore — lasciarlo così com'è (ignorare l'avviso per questa sessione)

Questo meccanismo impedisce ai file non autorizzati di causare eventuali problemi al funzionamento del dispositivo Ketron durante la riproduzione o il caricamento — ad esempio blocchi, errori o comportamenti imprevisti causati da file estranei che non dovrebbero essere presenti.

Intelligente Eindringling-Erkennung
🛡 Intelligenter Schutz

Event Studio Pro verwendet eine intelligente Technologie, die automatisch alle Dateien erkennt, die nicht in die Ordner USER_VOICE, USER_STYLE, REGISTRATION oder PERFORMANCE gehören — zum Beispiel Textdateien, Bilder oder andere Dateitypen, die das Ketron Event Gerät nicht erkennt. Diese werden als "Eindringlinge" bezeichnet.

Wenn Sie einen dieser Ordner in das Programm laden, werden alle Eindringlinge angezeigt und das Programm bietet drei Optionen für jeden von ihnen:

  • Delete — die nicht autorisierte Datei dauerhaft entfernen
  • Move — die Datei an einen anderen Ort auf Ihrem PC verschieben (außerhalb des Ordners)
  • Ignore — sie unverändert lassen (Warnung für diese Sitzung verwerfen)

Dieser Mechanismus verhindert, dass nicht autorisierte Dateien mögliche Probleme beim Betrieb des Ketron-Geräts verursachen während der Wiedergabe oder des Ladens — zum Beispiel Einfrierungen, Fehler oder unerwartetes Verhalten verursacht durch Fremddateien, die dort nicht sein sollten.

Умное распознавание "чужих" файлов
🛡 Умная защита

Event Studio Pro использует интеллектуальную технологию, которая автоматически распознаёт все файлы, не принадлежащие к папкам USER_VOICE, USER_STYLE, REGISTRATION или PERFORMANCE — например, текстовые файлы, изображения или любые другие типы файлов, которые устройство Ketron Event не распознаёт. Эти файлы называются "чужими" (intruders).

Когда вы загружаете одну из этих папок в программу, все чужие файлы отображаются, и программа предлагает три варианта для каждого из них:

  • Delete — окончательно удалить несанкционированный файл
  • Move — переместить файл в другое место на вашем ПК (вне папки)
  • Ignore — оставить как есть (отклонить предупреждение для текущей сессии)

Этот механизм предотвращает возможные проблемы в работе устройства Ketron, вызываемые несанкционированными файлами во время воспроизведения или загрузки — например, зависания, ошибки или неожиданное поведение из-за посторонних файлов, которых там не должно быть.

🛡 Om antivirus blockerar uppdateringen

Vissa antivirusprogram (Windows Defender, Avast osv.) kan flagga uppdateringsfilen som misstänkt. Detta är ett falskt larm — Event Studio Pro är säker. För att uppdateringar ska fungera normalt, lägg till EventStudioPro-mappen i antivirus-undantagen:

Windows Defender (vanligast):

  1. Öppna Windows-säkerhet (sök i Start-menyn)
  2. Klicka på Skydd mot virus och hot
  3. Klicka på Hantera inställningar
  4. Rulla till Undantag → klicka på Lägg till eller ta bort undantag
  5. Klicka på Lägg till ett undantag → Mapp
  6. Välj din EventStudioPro-mapp (t.ex. C:\EventStudioPro)
  7. Starta om Event Studio Pro — uppdateringar fungerar nu normalt

VirusTotal-skanning: VIRUSTOTAL_LINK_PLACEHOLDER

🚫 Arbeta INTE direkt från Ketron-enheten

Det avrådes starkt från att öppna mapparna USER_VOICE, USER_STYLE, REGISTRATION eller PERFORMANCE direkt från Ketron Event-tangentbordet eller ljudmodulen via USB. Ett misstag eller en oavsiktlig åtgärd kan radera en hel mapp eller dess innehåll.

Kopiera alltid mapparna till din PC först, arbeta med kopian och överför sedan de redigerade filerna tillbaka till enheten.

📜 Ansvarsfriskrivning

Baltik Sound ansvarar inte för eventuell dataförlust, skadade filer eller andra problem som kan uppstå vid användning av Event Studio Pro. Genom att använda programmet accepterar du fullt ansvar för dina data och för att upprätthålla dina egna säkerhetskopior.

3
Smart detektering av "inkräktare"
🛡 Smart skydd

Event Studio Pro använder smart teknik som automatiskt upptäcker alla filer som inte hör hemma i mapparna USER_VOICE, USER_STYLE, REGISTRATION eller PERFORMANCE — till exempel textfiler, bilder eller andra filtyper som Ketron Event-enheten inte känner igen. Dessa kallas "inkräktare".

När du laddar en av dessa mappar i programmet visas alla inkräktare och programmet erbjuder tre alternativ för var och en:

  • Delete — ta bort den obehöriga filen permanent
  • Move — flytta filen någon annanstans på din PC (utanför mappen)
  • Ignore — lämna den som den är (avvisa varningen för denna session)

Denna mekanism förhindrar att obehöriga filer orsakar eventuella problem med Ketron-enhetens drift under uppspelning eller laddning — till exempel frysningar, fel eller oväntat beteende orsakat av främmande filer som inte borde vara där.

Webbläsar- och antivirusvarningar — läs noga
📥 Webbläsarvarningar vid nedladdning

När du laddar ner EventStudioPro.exe från nedladdningslänken kan din webbläsare (Chrome, Edge, Firefox osv.) visa en eller flera varningar. Dessa är alla normala för all ny programvara och betyder INTE att filen är osäker.

Du kan se något av följande meddelanden:

  • "EventStudioPro.exe isn't commonly downloaded" — webbläsaren varnar om filer som ännu inte har laddats ner många gånger
  • "Confirm you are not a robot" — en extra säkerhetskontroll av webbläsaren
